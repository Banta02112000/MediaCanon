# CanonSync
Flet (Python) Android app: reconciles IMDb + Trakt, expands franchises via TMDB collections and Gemini,
and lists missing canon after subtracting your Exclusion Matrix.

Build without Android Studio: push this folder to GitHub, run the "Build APK" workflow, download the
`canonsync-apk` artifact. Local logic tests: `python tests/test_core.py`.
